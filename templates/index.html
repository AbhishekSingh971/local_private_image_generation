Face library · Persistent profiles

Create a new face profile

Give each consenting person or fictional adult model a separate profile. Each profile has its own photo dataset, trigger token, and trained adapter; adding a new face will not mix it with existing faces.

For useful training, aim for 15–30 clear photos of the same face, with different angles and lighting. Each file is limited to 8 MB. Use your own photos or images with permission.

Privacy and hardware

Local-only mode sends no inference requests to RunPod. Enabling cloud mode sends only the data required for the requested task. Do not use another person's face without permission.

Current local CPU mode can be slow on 8 GB RAM. RTX 3090 has 24 GB VRAM, but cloud use incurs charges while the Pod is running.

The GPU toggle routes requests only; it never creates, purchases, starts, stops, or terminates a RunPod Pod. Configure the remote worker and review billing/storage settings before use.
